# Plugin icon

The 2.0.0 icon is installed at `src/Resources/config/plugin.png`, the standard Shopware plugin icon location. It replaces the previous dark icon with a light background and a modular page-layout mark.

Generated using the built-in image generation tool. Exact final prompt:

> Use case: logo-brand. Asset type: square Shopware plugin icon for Ultimate CMS Tools, a professional visual page builder with modular content grids. Create one modern, fresh, light icon. A bold, memorable modular layout mark made of three or four rounded rectangular content tiles, arranged as a clean asymmetric page grid. Soft ivory-white background, bright clear azure blue and fresh mint accents with a small warm peach accent. Refined subtle depth, crisp edges, generous negative space, polished contemporary software branding. Large central symbol remains very readable at 40px. Square 1024 by 1024 composition. No text, no letters, no watermark, no dark background, no black outlines, no border, no elaborate tiny detail. Icon itself, not a mockup.
