# Bundled CMS icons

122 regular/solid icons from `@shopware-ag/meteor-icon-kit` 5.10.0 by Shopware AG, licensed under MIT (see LICENSE.md). Source: https://github.com/shopware/meteor/tree/main/packages/icon-kit

The catalog is the single source for Button and Icon List options, editor previews and storefront rendering. SVGs are trusted, bundled package data, not user markup. IDs are removed to avoid duplicate DOM identifiers; icons are decorative and use currentColor.

Legacy names are preserved: arrow-* uses long-arrow-*, chart uses chart-line, shop uses storefront and thumb-up uses thumbs-up. New icons must be reviewed for safe SVG elements/attributes and bundled in both variants. Never load SVG URLs or markup supplied by CMS users.
